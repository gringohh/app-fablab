Relais Drive

Première configuration

L'application a besoin d'un identifiant client Google (gratuit, à créer une seule fois avec ton compte Gmail).

  1. Ouvre console.cloud.google.com avec ton Gmail et crée un projet « Relais Drive ».
  2. Active l'API Google Drive.
  3. Configure l'écran de consentement (type « Externe »), ajoute ton Gmail comme utilisateur test.
  4. Crée un identifiant « ID client OAuth » de type Application Web, avec comme origine JavaScript autorisée :
  5. Colle ci-dessous l'ID client (il finit par .apps.googleusercontent.com).

Le guide détaillé est dans le fichier LISEZMOI.md du dossier relais-drive.

Choisis un ou plusieurs fichiers .zip Ils sont décompressés ici, sans rien mélanger dans Téléchargements.

Astuce : dans l'app Fichiers, sélectionne un .zip → Partager → Relais Drive.

À envoyer

Chaque lot devient un dossier dans sur ton Drive. Tu peux renommer le dossier.
