# app-fablab
outil pour fablab

- `fablab.html` : plateforme de gestion du fablab
- [`projets-sti2d/`](projets-sti2d/LISEZMOI.md) : application « Projet » : tableau de bord des projets Seconde SI-CIT, Première STI2D et Terminale 2I2D (fiche projet, diagrammes, planning, export PDF, serveur local)
- [`relais-drive/`](relais-drive/LISEZMOI.md) : application « Relais Drive » pour tablette Android : décompresse un .zip et l'envoie, dossiers compris, sur Google Drive (pour que Claude puisse le lire)
